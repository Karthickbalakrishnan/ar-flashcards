# Research Framing

## Project Title
Embodied Learning with AR and Interactive 3D Visualization for Science Education

## Abstract

This project investigates how immersive and embodied interfaces can support conceptual understanding in educational settings. By integrating augmented reality (AR), 3D visualization, and interactive flashcard-based review, the system explores how students engage with complex scientific content such as anatomy and molecular structure.

The prototype combines an AR interface for spatial exploration and a 3D educational flashcard system for concept understanding and recall. The work is situated within HCI and immersive learning research, with emphasis on embodied cognition, spatial reasoning, and multimodal educational design.

The project addresses a practical and theoretical question: can immersive interfaces improve learning outcomes and engagement when compared to traditional static learning materials?

## Research Questions

1. How does an AR-based 3D educational interface influence conceptual understanding compared to static 2D explanations?
2. To what extent do embodied interactions such as rotation, zoom, and spatial manipulation support learning and memory?
3. Can interactive visualization improve learner engagement and reduce cognitive overload in scientific education?
4. How do students perceive usability, presence, and educational value in a mobile-first immersive learning system?

## Hypotheses

### H1
Students using interactive 3D and AR-based learning interfaces will demonstrate greater conceptual understanding than students using conventional 2D instructional materials alone.

### H2
Embodied interaction in AR will improve spatial reasoning and retention for complex scientific concepts, particularly those requiring structure-based understanding.

### H3
Combining visual 3D representations with retrieval-based flashcards will improve active recall and learning retention compared to passive viewing alone.

### H4
A mobile-first immersive design will be perceived as usable and engaging by students, provided the interface reduces cognitive friction and prioritizes clarity.

## Theoretical Grounding

This project is informed by core ideas from HCI and learning science:

- Embodied cognition: learning is supported when learners interact with representations physically and spatially
- Multimedia learning theory: combining visuals, explanations, and interaction can support understanding
- Spatial cognition: 3D representations may aid reasoning for complex objects and systems
- Active recall: practice-based review strengthens memory and transfer
- Presence and immersion: digital embodiment may increase engagement and perceived comprehension

## Why This Project Is Relevant

Many educational tools still rely on static visuals and linear explanations, which may fail to represent:
- complex spatial relationships
- dynamic biological changes
- progressive cause-and-effect pathways
- interactive conceptual reasoning

This project responds to that limitation by designing a learning environment where students can:
- manipulate visual scientific structures
- inspect them from multiple angles
- connect representations to conceptual explanations
- test recall through flashcard-style review

## Novelty

The project contributes to HCI and educational technology by combining:
- AR-based visualization
- educational flashcard review
- scientific concept explanation
- mobile-first interaction design
- embodied learning approach

The novelty is not only the technical integration but also the educational framing: the system is designed as an experimental prototype for studying how immersive interfaces affect learning and understanding.
